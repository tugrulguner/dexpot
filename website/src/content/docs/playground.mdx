# Browser-local request workbench

Explore the request/response contract demonstrated by [`examples/typed_crud.py`](https://github.com/tugrulguner/dexpot/blob/main/examples/typed_crud.py). The workbench computes bounded CRUD outcomes in this tab only; it does not call the Python framework or send requests to a server.

The example starts with item `1` (`starter`, `9.99`), creates monotonic IDs, returns `200` with `{ "deleted": id }` for successful deletes, and uses `detail` for error bodies. The browser preview allows at most 20 live items and resets when asked or when the page reloads. The latency record above is a separately measured local HTTP run—not a browser timer and not output from this preview.
